Что было

Для чемпионата культурных проектов я придумал настолку с цифровым слоем. Показал людям и услышал жесткое «не то».

Что сделал

Вывод для вас

Имя элемента, по которому CSS понимает, что красить: .button-main

Правила CSS, которые меняют вид страницы на маленьком экране.

Всё, что видит пользователь в браузере.

Бэкенд

То, что работает на сервере: база данных, заявки, оплата.

  1. Скопируйте промпт из брифа группы (ссылку пришлю в чат)

Практика 2 из 35 минут

Забираем код себе

Google AI Studio

Кнопка скачивания проекта (Download / Export) или «Export to GitHub». Получите ZIP с проектом.

Lovable

Подключите GitHub в настройках проекта: код сам появится в репозитории.

ChatGPT, Claude, GigaChat

Попросите: «Выдай сайт одним файлом index.html, CSS и JS внутри». Сохраните текст в файл.

Проверка

Дважды кликните по index.html. Открылся в браузере? Значит, это и есть сайт.

Главный момент пары: сайт это просто файл. Его можно положить куда угодно, и он будет работать.

Практика 3 из 310 минут · без терминала

Публикуем на GitHub Pages

  1. New repository, имя my-site, Public
  2. Add file, затем Upload files: перетащите index.html, нажмите Commit
  3. Settings, раздел Pages: Deploy from a branch, main, / (root), Save
  4. Через 1-2 минуты сайт по адресу имя.github.io/my-site
docs.github.com · GitHub Pages
Официальная инструкция на русском
Для тех, кто успелReact / Vite из AI Studio или Lovable

Собираем проект на своем компьютере

  1. Установите Node.js LTS с nodejs.org
  2. Распакуйте ZIP, откройте папку в терминале
  3. npm install, потом npm run dev: сайт на localhost
  4. npm run build создаст папку dist
  5. Загрузите содержимое dist в репозиторий, как в практике 3
// vite.config.ts
export default defineConfig({
  base: '/my-site/',
  plugins: [react()],
})

Без строки base на GitHub Pages будет белый экран: сайт ищет файлы в корне домена, а лежит в папке репозитория. Самый частый вопрос после пары.

Git push, и код уже проверен

Проект

Я делаю kornishon: платформу, где разработчики решают реальные задачи и отправляют код через Git.

Как работает

Человек делает git push, а автоматика сама запускает проверки: линтер, тесты, нагрузку. Никто не носит файлы руками.

Для вас

Вы сегодня сделали первый шаг того же пути: код лежит в GitHub и сам превращается в сайт. Дальше можно настроить автодеплой.

11 · ДемоОсновной шаблон
Создай современный одностраничный продающий лендинг на русском.

БИЗНЕС: [название, что продаем, город]
АУДИТОРИЯ: [кто клиент, чего хочет, чего боится]
ОТЛИЧИЕ: [УТП]
ДЕЙСТВИЕ: [записаться / купить / позвонить]
СТИЛЬ: [настроение], шрифты Google Fonts с кириллицей,
mobile first, анимации при скролле.
Избегай шаблонного вида AI-сайтов: никаких фиолетовых
градиентов и одинаковых карточек с иконками в кружках.

СТРУКТУРА: шапка, первый экран с оффером и кнопкой,
цифры доверия, боли, услуги с ценами, 4 шага, отзывы,
FAQ, форма (имя, телефон, обязательный чекбокс согласия
на обработку персональных данных), футер.

SEO: title, description, Open Graph, один H1.
